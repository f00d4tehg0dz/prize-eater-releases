# Security policy

If you find a security problem in Prize Eater, please report it privately rather than in a public issue.

Use **[Report a vulnerability](https://github.com/f00d4tehg0dz/prize-eater-releases/security/advisories/new)** on this repository. Include the Prize Eater version (shown in the installer name or Windows "Apps" list), what you found, and steps to reproduce it.

You'll get a reply within a few days. Fixes ship as a new release on the [Releases page](https://github.com/f00d4tehg0dz/prize-eater-releases/releases).
